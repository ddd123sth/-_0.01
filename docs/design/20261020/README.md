## 设计判断

视觉锚点是用户已有图标中的蓝紫绣球、轻盈花瓣、水润光感和细腻植物笔触。登录页呈现完整原图标，游戏号与设置页延续它的色彩、留白和花园插画；图标不重画，也不另造品牌记号。三版均围绕同一花园主题展开，以晨光、雨后与月色形成不同氛围，同时保持账号、设置和操作区的清楚层级。

| 项目 | 设计安排 |
| --- | --- |
| 视觉方向 | 默认「晴空花屿」；另有「雨后花径」「月色花庭」，均以原图标和花园插画为中心 |
| 主要色值 | 晴空背景 `#F4F7FF`、正文 `#30375B`、强调 `#7186D4`；雨后强调 `#719BA7`；月色强调 `#9B86C4` |
| 标题与描述 | 标题「花开无尽夏」；描述「雨落有晴天」，三版保持一致 |
| 页面标题 | 25–29 px，清楚区分页面与卡片层级 |
| 内容层级 | 主要功能 14–16 px；设置项 13 px；辅助说明主要为 11–12 px；极次要时间、标签及板图标注为 9–10 px |
| 表面 | 珍珠白卡面、柔和圆角、轻边界；花园图像集中在品牌入口与横幅，表单正文保持安静可读 |
| 底栏 | 保留游戏号 / 设置 / 日志 / 我的四栏，选中项用柔和底色、文字和图标共同表达 |

## 页面与操作范围

1. **登录**：完整用户原图标、标题「花开无尽夏」与描述「雨落有晴天」；账号、密码和登录主动作有明确顺序。原型登录按钮仅切换画面，不验证身份、不提交输入值。请勿向原型输入真实凭据。
2. **游戏号**：顶部仅展示简洁品牌与本机状态；按运行中/已停止扫读。账号卡突出昵称、状态、设置与日志入口及一个开始/停止动作。示例使用项目已指定昵称，不添加游戏账号。
3. **种花收花**：三个功能独立开关，种植模式、分组和保留水滴按实际能力组织。种植模式沿用「库存最少 / 指定花朵 / 指定品质 / 置顶花朵」；分组仅在源码已有的 4、8、16、32、64 间切换。品质、黑名单和种植数量（目标枝数）放在更多设置入口。
4. **交订单**：居民、绸缎、建材、顾客、宫廷、组团六类订单独立开关；类别参数进入二级面板。居民、绸缎、建材的视频单随所属总开关启停，不另加视频开关。日常任务奖励拥有独立、默认关闭的卡片，仅表达已完成任务的领取，不含活跃度宝箱、周常或底层任务执行。
5. **花艺**：指定花艺、成品目标库存、自动补货及两类首做奖励保留独立入口。提示顾客需求优先及官方确认后交付；状态读不到不作为拒单依据。
6. **日志**：时间线呈现动作与等待原因，顶部账号切换、类别筛选；等待与完成用文字和颜色同时区分。示例没有任何官服确认或真实验收含义。
7. **我的**：软件身份与游戏号分开表达；授权、密码、日志同步、运行服务、电池说明和网络出口分组。网络出口从游戏号首页移到此处是设计提案，正式接入仍须核对现有功能完整性。

卡片内部具体覆盖：四种种植模式及其名单门限、12 个真实静态花种的搜索多选、5 档品质、黑名单、分组 4/8/16/32/64、种植数量与保留水滴；居民/绸缎/建材数量上限，顾客 1/2/3 档及自动拒单，宫廷禁交品质，组团真实操作/免费接单/元宝加单及留量；日常奖励各状态；花艺配方、目标库存、补货、首做图鉴和分享奖励。同名花艺的已选摘要携带配方，不混淆不同配花。

操作与反馈覆盖：注册和登录帮助、添加游戏号的表单/核对中/成功/部分未读取/未核对/失败、账号更多和启停状态、移除确认、未保存离开、保存成功与结果未确认；软件授权的有效/未取得/过期/停用/离线宽限内/期限待核实；改密、退出、日志同步队列/配额/未归属/缺口及各反馈、资料归属、设备状态/后台通知与电池设置、统一网络出口的应用/清除/失败；日志来源、12 类筛选、日期、每页 15 条分页、详情、读取中/空/失败。

所有控件只更新当前页面内存。账号配置草稿按账号隔离；分类切换共享同一账号草稿；二级面板取消不应用，完成后更新父草稿，主页面保存才更新本次内存中的已保存版本。未保存离开可保存、放弃或继续编辑。选择器支持搜索、全选可见、清空、确认和取消。表单支持必填、整数、量程与密码长度提示；关闭所属总开关也不能携带非法数字保存。花艺首做开关随制作总开关禁用。刷新即可重置。

`Content-Security-Policy` 禁止连接及表单提交；没有 fetch、XHR、WebSocket、浏览器本地持久化或引擎导入。忙碌/成功/错误面板是可选择的设计场景，不是伪造的网络响应；正式接入时仍由实际结果驱动。保存与启停主入口沿用直接操作后反馈，不增加额外审批。

本次配置初值中所有业务开关均关闭；账号列表另保留一个运行中的版式示意。**正式 App 的新账号及功能默认关闭要求不变**。生产接入时必须读取真实账户配置，不能将本稿的示意值用作业务默认值。目录名称与编号摘自本仓静态官方表，仅用于选择器设计，不代表任何账号已解锁、拥有或能够制作。
