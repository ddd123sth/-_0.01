# 完整设置原型

本次交付按用户要求补齐全部设置，统一现有 Moon 风格、减少重复和说明文字。参考项目为 `D:/AI/AiCode/我的花园世界`，以当前源码暴露的设置为准。

共 8 类、239 项设置：53 个业务功能，加 10 个账号与节奏字段。数据按 54 个归属组织；账号与节奏拆成 3 张功能卡后，共有 56 个功能入口。主界面承载 50 项，详情承载 189 项，每项只有一个编辑归属。页面沿用 Moon「交订单」的分组圆角白卡、图标、标题、短摘要、箭头及详情底栏；名单选择器只负责选名单。

花架与花艺改为无编辑控件的三入口总览：做花艺 4 项、卖花艺 8 项、领取奖励 2 项。每次进入一张独立详情；卖花艺的时间与金币留量仅在对应开关打开后显示，隐藏时保留原值。子详情完成先回到整组草稿，整组取消会丢弃本次全部修改。详细规则集中在每页一个入口。

## 数据与交互

静态名单取自参考项目真实目录，用于展示可选项目，不代表当前账号库存、解锁进度或资格。成员 UID 在原型中手动输入：参考项目缺少对应动态选项，本次补充的是设计输入，不能据此称 App 已支持该能力。

修改、保存、取消及账号切换用于演示草稿与隔离；复制和分享仅在本页内存中模拟，不连接服务，刷新后不保证保留。
